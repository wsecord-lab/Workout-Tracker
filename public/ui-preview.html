3 · "Workout Mode" concept

A toggle (per-session or in the header) that strips the UI down to only what you need during a live workout. The trainer still has access to all features in the normal view. The question is: who benefits from this, and how much extra surface area does it add?

Option B — No "mode", just polish the existing UI
Since the trainer is the primary user, a dedicated "workout mode" adds complexity: a toggle to maintain, two UI states to test, and the risk of confusion about which mode you're in.
Instead, the same goals can be achieved by:
  • Collapsing the bulk-add section by default
  • Promoting "Repeat last" as a pill button in the quick-add form
  • Adding set numbers + icon buttons to each set row
  • Pre-filling weight/reps from the previous set
This gives 80% of the workout-mode benefit with none of the added surface area. If a true mode toggle makes sense later, it can be added on top of an already-polished UI.
Recommended starting point — lower risk, faster to ship.
